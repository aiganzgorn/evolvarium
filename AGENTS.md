# Правила репозитория `evolvarium`

Инструкция для агента (opencode). Относится только к этому репозиторию.

## Границы

- **Ядро симуляции — чистое.** `src/sim.ts` и `src/genome.ts` не знают ни про DOM, ни про
  canvas, ни про `window`. Любой шаг симуляции должен запускаться в Node.
- **Рендер только читает.** `src/render.ts` не меняет состояние мира. Всё, что меняет мир,
  живёт в `src/sim.ts`.
- **Детерминизм.** В симуляции нет `Math.random()`, `Date.now()` и обращений к глобальному
  состоянию. Случайность — только через `world.rng` из `src/rng.ts`. Один seed — один мир.
- **Внешний вид.** Canvas масштабируется от реального размера окна: координаты мира
  (1440×900) переводятся в пиксели через `min(vw/W, vh/H)`, поэтому пропорции одинаковы на
  любом экране. HUD и подсказка не перекрывают Плюшу. Перед тем как говорить «готово»,
  убедись, что это видно в браузере, а не только в коде.
- **Ничего лишнего.** Новая зависимость — только если без неё никак. Фича, которую не
  просили, не добавляется.

## Порядок работы

1. Правки в `main`, без долгих веток.
2. `npm test` и `npm run build` зелёные — иначе работа не закончена.
3. Запись в `CHANGELOG.md`: что изменилось и зачем, одной строкой на пункт.
4. Коммит и пуш в `origin/main` сразу, не дожидаясь отдельной просьбы.

## Стиль

- Комментарии в коде — по-английски и только там, где код не объясняет сам себя.
- Текст интерфейса и документации — по-русски.
- Имена файлов и функций — по-английски, коротко.
