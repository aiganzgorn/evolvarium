# Эволюляриум

Маленький мир, в котором блобы живут своей жизнью. Пока просто живут — эволюция впереди.

**Плюша** — первый блоб и талисман проекта. Её размер задан прямо в координатах мира
(`SIZE` в `src/config.ts`). Глаз у неё пока нет, есть только румянец; на макушке растёт
росток — это мутация фотосинтеза. Она дышит и читает свой мозг. Стоит на месте.

## Голова

Внутри головы — маленькая машина:

- **память** на 60 ячеек;
- **pc** — какая ячейка читается сейчас;
- **энергия** — 20 на старте, потолок 30;
- **пакет** — то, что путешествует между ячейками; у него свой потолок 10;
- **mutations** — список особенностей тела, которые мозг умеет дёргать. У первой Плюши
  там один фотосинтез.

### Язык ячейки

В ячейке одно число: **последняя цифра — операция, остальное — аргумент**. Для вызова
мутации аргумент делится дальше: `мутация = arg % 10`, `действие = ⌊arg / 10⌋`.

| число | что делает | цена |
|---|---|---|
| `0` | сохранение энергии, ничего | 0 |
| `1` | перейти на ячейку `arg` (0 — первая) | `JUMP_COST` |
| `2` | фотосинтез (мутация 0), действие 0 | `USE_COST` |
| `12` | ножка (мутация 1), действие 0 — повернуть вправо | `USE_COST` |
| `112` | ножка, действие 1 — повернуть влево | `USE_COST` |
| `212` | ножка, действие 2 — схватить землю | `USE_COST` |
| `312` | ножка, действие 3 — отпустить землю | `USE_COST` |

Один тик — одна прочитанная ячейка. Если прыжка не было, `pc` идёт дальше, после 60-й —
на первую.

### Мутации

Мутация — объект с общим интерфейсом: `id` (он же ключ отрисовки), `label`, список
`actions` (что мозг может попросить, с номерами ячеек) и `act(ctx)`, который возвращает
число — результат, попадающий в пакет. Каждая мутация обязана быть видна на теле.

**Фотосинтез** смотрит на глобальный свет (75%) и возвращает `2 × свет`: 2 при 100%, 1.5 при
75%, 0 при 0%. Рисуется ростком на макушке.

**Ножка** — жёсткая палочка без суставов, длина задаётся при рождении и хранится в самой
мутации (`leg.length`, по умолчанию `LEG_LENGTH = 70`), так что особи могут быть с разной
ногой. Висит на петле внизу тела и поворачивается на `12°` за действие, в пределах ±180° от
тела. Когда кончик держит землю, палочка не вращается относительно тела — **вместо этого тело
поворачивается вокруг точки захвата**: радиус `leg.length` сохраняется, нога не растягивается.
Схваченная нога нарисована золотой точкой на кончике, свободная — полым кружком. Длина видна
в панели.

### Стартовая программа

Программа строится из сида: `?seed=123` — другая Плюша с другой памятью. Начинается с 20–24
фотосинтезов (это топливо), затем один **шаг**: захват → 4–5 поворотов в одну сторону →
отпуск → столько же поворотов обратно → захват → повороты обратно → отпуск → доводка.
Поворот в одну сторону тащит тело вокруг точки захвата, обратный возвращает его в вертикаль,
поэтому тело **идёт, не кувыркаясь**, и за жизнь проходит ~90 единиц (примерно две своих
ширины), после чего энергия кончается.

Почему именно так, а не «просто идти прямо»: пока нога держит землю, поворот крутит **тело**
(палка жёсткая), а свободный поворот двигает только ногу. Значит, за проход тело набирает
ровно сумму поворотов на захвате; программа без условий и без записи в память всегда
периодична, то есть путь — окружность постоянной кривизны. Гасить кривизну можно только
обратным поворотом на следующем захвате — это и есть шаг. Прямая походка требует либо двух
ног (одна держит, вторая переставляется), либо сустава.

Экономика: каждый вызов мутации стоит `USE_COST = 1`, фотосинтез при 75% даёт 1.5, а пакет
держит не больше `PACKET_MAX` — поэтому длинная программа шагов не окупается. Хочешь, чтобы
она жила дольше: `START_ENERGY`, `LIGHT`, `USE_COST`, `PACKET_MAX` в `src/config.ts`.

### Пакет и деньги

Стоимость платится **сначала из пакета**, и только если в пакете пусто — из головы.
Результат мутации сразу ложится в пакет. На переходе в первую ячейку пакет переливается в
голову до её потолка; излишек остаётся в пакете, пока не упрётся в его потолок — дальше
теряется.

Стартовая программа: 10 фотосинтезов, затем `212` (схватить), четыре `12` (тело отъезжает на
48° вокруг точки), `312` (отпустить) и прыжок в начало. За проход: приход 15, расход 17 —
итого **−2**. С 20 энергии Плюша живёт 10 проходов, то есть 600 тиков = 30 секунд, потом
падает и оставляет органику. Экономика — крутилки: `LIGHT`, `USE_COST`, `START_ENERGY`.

## Крутилки

Все числа проекта — в `src/config.ts`: размер мира, размер Плюши, частота тика, память,
энергия, потолки головы и пакета, цена прыжка и вызова мутации, свет, длина и шаг ножки,
`ORG_BASE`, базовый геном и параметры мутации. Язык мозга (`OP_REST`, `OP_JUMP`, `OP_USE`) и
правило кодировки аргумента лежат в `src/sim.ts` — это не настройка, а смысл программы.

## Управление

| | |
|---|---|
| **пробел** | запустить / поставить на паузу |
| **→ ↓** | один тик вперёд (мир при этом встаёт на паузу) |
| **← ↑** | один тик назад |
| **клик по Плюше** | панель с памятью |

Назад можно отмотать `HISTORY_TICKS` тиков (200, то есть 10 секунд в реальном времени) —
для каждого шага хранится полный снимок мира. Глубина истории видна в HUD.

## Клик по Плюше

Клик по ней открывает панель справа, а вокруг неё появляется тонкая золотая рамка —
она охватывает тело, росток и подпись, чтобы было видно, кого именно ты выбрал. В панели:
энергия, указатель, содержимое пакета (сколько лежит,
потолок и что в него вошло последним), мутации со списком действий и номерами ячеек, и вся
память из 60 ячеек. Текущая ячейка обведена золотым, вызовы мутации зелёные, прыжок синий.

## Запуск

Нужен Node ≥ 20.

```sh
npm install
npm run dev      # http://localhost:5173
```

`?seed=123` в адресе — другой мир. Один и тот же seed всегда даёт одинаковую симуляцию.

Мир стартует на паузе. **Пробел** — запустить и поставить на паузу.

## Проверки и сборка

```sh
npm test         # headless-проверка ядра симуляции
npm run build    # tsc --noEmit + vite build → dist/
npm run preview  # посмотреть собранное
```

## Структура

```
src/rng.ts       mulberry32 — детерминированный генератор
src/genome.ts    геном, мутация, цвет
src/config.ts    все крутилки проекта
src/mutations.ts мутации: общий интерфейс и логика
src/sim.ts       ядро симуляции: чистые данные, ни DOM, ни canvas
src/render.ts    только рисование по состоянию мира
src/main.ts      браузерная точка входа: canvas, resize, цикл 20 тиков/с
tools/sim-test.mjs  headless self-check
```

Правило, на котором всё держится: **`sim.ts` не знает про браузер**. Поэтому его можно
гонять в Node — тысячи поколений за секунды, без отрисовки.
