# Эволюляриум

Маленький мир, в котором блобы живут своей жизнью. Пока просто живут — эволюция впереди.

**Плюша** — первый блоб и талисман проекта. Её размер задан прямо в координатах мира
(`SIZE` в `src/sim.ts`). Глаз у неё пока нет, есть только румянец: она дышит и читает свой
мозг. Стоит на месте.

## Голова

Внутри головы — маленькая машина:

- **память** на 60 ячеек, в каждой число, и это число и есть операция;
- **pc** — какая ячейка читается сейчас;
- **энергия** — 20 на старте;
- **mutations** — список особенностей тела, которые мозг будет дёргать, когда появятся
  соответствующие операции. Пока пуст.

Один тик — одна прочитанная ячейка. `0` — «сохранение энергии», ничего не делает и ничего не
стоит. `1` — «перейти на ячейку N», параметр по умолчанию `0` (первая ячейка), стоит 1
энергию. Иначе `pc` идёт на следующую ячейку, после 60-й — на первую.

Стартовая программа: 59 ячеек отдыха и прыжок в конце. Полный проход по памяти стоит 1
энергию, поэтому с 20 энергии Плюша умирает через 20 проходов — 1200 тиков, минута на
экране. Когда энергия дошла до нуля, она исчезает; когда в мире не осталось живых, тик
останавливается сам.

## Запуск

Нужен Node ≥ 20.

```sh
npm install
npm run dev      # http://localhost:5173
```

`?seed=123` в адресе — другой мир. Один и тот же seed всегда даёт одинаковую симуляцию.

Мир стартует на паузе. **Пробел** — запустить и поставить на паузу.

## Проверки и сборка

```sh
npm test         # headless-проверка ядра симуляции
npm run build    # tsc --noEmit + vite build → dist/
npm run preview  # посмотреть собранное
```

## Структура

```
src/rng.ts       mulberry32 — детерминированный генератор
src/genome.ts    геном, мутация, цвет
src/sim.ts       ядро симуляции: чистые данные, ни DOM, ни canvas
src/render.ts    только рисование по состоянию мира
src/main.ts      браузерная точка входа: canvas, resize, цикл 20 тиков/с
tools/sim-test.mjs  headless self-check
```

Правило, на котором всё держится: **`sim.ts` не знает про браузер**. Поэтому его можно
гонять в Node — тысячи поколений за секунды, без отрисовки.
