# Changelog

## 0.1.0 — 2026-10-21

- Новый проект: Vite + TypeScript + Canvas2D, без Construct.
- Чистое ядро симуляции (`sim.ts`, `genome.ts`) — запускается headless в Node.
- Детерминированный RNG (mulberry32), мир 96×54, 12 блобов с геномом.
- Рендер на canvas: сетка, блобы с глазами, румянцем и морганием; Плюша подписана.
- `tools/sim-test.mjs` — проверка детерминизма и границ мира.
